# JCORE Transformer and Energy Services Limited

Next.js website for transformer repair, manufacturing and technical training.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository into Vercel, select the Next.js framework preset, and deploy the `main` branch.

## Before production launch

- The enquiry form only reviews entries; **it does not send or save submissions**. Configure a secure submission endpoint and approved company inbox.
- Confirm company content, service scope and official branding.
- Replace illustrative external photography with approved licensed assets.
- Add a privacy notice and spam protection before enabling submissions.
- Run build and responsive QA.
